# NetMaster — progress demo

Public GitHub Pages companion for the KAUST course *Advanced Topics in Computer Networks* (Shihada).

Live site: **https://xiehuanyi.github.io/netops-agents-viz/**

The page is a static visualization of work already measured on [NetOpsBench](https://github.com/NetX-lab/NetOpsBench):

1. **Progress** — A1 loop, A2 harness vs OpenCode, A3 four-desk NOC, and the next plan (Large / Xlarge / Fat-tree K=8, 12, 18 + model swap)
2. **Replay** — all 13 scored XS cases. Each frozen `netops` call has its own motion and a result chip (ping echo or drop, traceroute hops, BGP Idle, config sheet, diagnosis stamp)
3. **Cloud** — word clouds of tools called and fault types the agent named
4. **Scores** — frozen Assignment 2 / Assignment 3 numbers

Presenter keys: `1`–`4` switch tabs, `Space` plays, arrows step. `#fabric` and `#noc` still open Replay.

No API keys and no full tool dumps. Lab code stays in the private repo `xiehuanyi/netops-agents`.
